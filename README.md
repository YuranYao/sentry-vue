# Vue Sentry Demo

这是一个基于 Vue 3 + Vite 的最小可运行项目，当前是一个简单的阅读清单页面，适合作为后续学习 Vue 项目集成 Sentry 的练习工程。

## 启动项目

```bash
npm install
npm run dev
```

打开终端提示的本地地址即可。生产构建可以使用：

```bash
npm run build
npm run preview
```

## 项目结构

- `src/main.js` 是应用入口，后续可以在这里初始化 Sentry。
- `src/App.vue` 是阅读清单页面。
- `src/style.css` 是页面样式。
